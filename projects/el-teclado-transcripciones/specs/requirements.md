# Requisitos Funcionales y No Funcionales
 
 ## Requisitos Funcionales (RF)
 A partir de la idea: *Aplicación de dictado de voz y transcripciones automáticas utilizando un teclado virtual y micrófono integrado (Turbo Whisper). Permite a los usuarios hablar y transcribir texto en tiempo real a cualquier aplicación, gestionar atajos de teclado, historial de transcripciones y proveedores de IA configurables.*
 *   **RF-01 (Autenticación):** El sistema debe permitir a los actores () iniciar sesión de forma segura.
 *   **RF-02 (Core):** El sistema debe resolver la problemática central: "Aplicación de dictado de voz y transcripciones automáticas utilizando un teclado virtual y micrófono integrado (Turbo Whisper). Permite a los usuarios hablar y transcribir texto en tiempo real a cualquier aplicación, gestionar atajos de teclado, historial de transcripciones y proveedores de IA configurables.".
 *   **RF-03 (Administración):** Se debe proveer un panel de control para gestionar recursos.
 
 ## Requisitos No Funcionales (RNF)
 *   **RNF-01 (Seguridad):** Cifrado de datos en tránsito (TLS/HTTPS).
 *   **RNF-02 (Rendimiento):** Tiempos de respuesta del backend inferiores a 300ms para endpoints CRUD.
 *   **RNF-03 (Usabilidad):** Interfaz fluida y accesible que cumpla con los estándares WCAG 2.1 AA.
